# Källkopior

`kartdata-source.json` skapas från bladet `Kartans namn`, intervallet
`A1:K162`, i arbetsboken *Kartans namn per fastighet (radgranskning
2026-07-22)*. Alla elva cellvärden per rad bevaras. Arbetsboken ändras inte.

`platsregister-seed.json` är grundstrukturen med Simons bekräftade beslut
tydligt skilda från ogranskade förslag. `platsnamn-seed.json` är det
källspårbara, additiva underlaget för historiska och alternativa namn samt
ännu oidentifierade holmnamn. Det publiceras som privata operationer, aldrig
som data i GitHub-paketet.
