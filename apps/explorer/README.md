# Explorer

Explorer är en skrivskyddad tvärvy över Korpholmens sju register. Den har ingen egen master och inga egna Dropbox-operationer.

- Personer öppnas först i en samlad läsvy.
- Båtar, fastigheter, handlingar och tävlingsår öppnas i appen som äger uppgiften.
- Okopplad källtext kan hittas, men visas separat och blir aldrig en personuppgift.
- Alla ändringar görs i respektive ägarapp.

Kör `npm test` i katalogen och `npm run build:publish` för att bygga det datafria publiceringspaketet.
