# Privat Klubbhistorik-data

Allt under denna mapp utom denna README är ignorerat av Git.

Källkopior läggs i `kallkopior/` och får aldrig redigeras efter kopiering.
Alla matrikelavskrifter ligger i `kallkopior/matriklar/` enligt ett gemensamt
schema. `kallkopior/matriklar/original/` innehåller begripliga kopienamn;
arkivoriginalens filnamn och bytes ändras aldrig.
Startmastern och kontrollrapporten byggs i `migrering-2026-08-02/`.
